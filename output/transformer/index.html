拆开一个 Transformer ↘

先校准一个概念

Transformer 是神经网络的一种架构。它仍使用可学习的参数、非线性变换、损失函数与反向传播。它的标志性变化，是用注意力组织位置之间的信息交换，而网络内部依然包含 MLP。

01 /

先认清三块积木

可以把一个序列看成一张表：每行是一个位置，每列是一个特征。Transformer 一边让行与行交换信息，一边更新每行的特征。

TOKEN → VECTOR

输入变成向量

文本被切成 token（字、子词或其他片段），经 Embedding 查表成为向量。token 不一定等于一个词；图像也可拆成 patch 作为输入单元。

MIX POSITIONS

Attention 交换信息

每个位置计算对其他可见位置的权重，再汇聚它们的内容。权重取决于当前输入，因此同一个 token 在不同语境中能得到不同表示。

TRANSFORM FEATURES

FFN 加工特征

逐位置前馈网络通常先升维、再非线性变换、再降维。同一层各位置共享这套参数；FFN 本身不直接交换不同位置的信息。

注意力，到底在算什么？

对每个位置生成三组向量：Q（Query）用于发起匹配，K（Key）用于被匹配，V（Value）提供被汇聚的内容。这些投影由训练学得，并不是人工填写的语义标签。

A = softmax(QKᵀ / √dk + M)

X 的形状是 n × d，单头 Q、K 为 n × dk，V 为 n × dv；A 为 n × n，输出为 n × dv。M 在允许位置取 0，在禁止位置取 −∞。softmax 对每一行归一化。

01 · 匹配

Q 与 K 点积

衡量投影空间中的匹配程度；除以 √dk，缓和维度增大造成的分数尺度增长。

02 · 筛选

加遮罩，做 softmax

把可见位置变成总和为 1 的权重。因果遮罩禁止看未来；padding 遮罩排除补齐位置。

03 · 汇聚

按权重加权 V

结果是内容向量的加权和。实验中的条形只展示权重 A，并没有展示 V 或最终向量。

04 · 多视角

多个 head 并行

各头使用各自的投影，输出拼接后经 WO 合并。不同头可以学到不同关系，但没有预设职责。

实验使用人工设定的 Q、K 并实时计算 softmax；“温度”仅用于观察分布尖锐程度，计算为 softmax((QKᵀ / √dk) / τ + M)。它不是原始架构必需的独立参数，也不是文本生成时的采样温度。权重大小不等于因果解释。

共同的底层：可微函数 + 参数学习

都能通过损失函数计算梯度，用反向传播和梯度优化更新参数。线性层、非线性、正则化等积木仍然适用；注意力机制也早于 Transformer，并可与 RNN 结合。

差异的核心：先验与灵活性的取舍

CNN 把局部性写进结构，RNN 把递推写进结构；Transformer 让内容决定交互权重。灵活并不保证在小数据、低延迟或算力受限条件下更优，需结合任务验证。

05 /

训练能并行，生成为什么还要逐步？

以自回归语言模型为例：训练时完整样本已经存在；生成时下一个 token 尚未知。这是两种不同的计算条件。

TRAINING

一次前向，多处预测

把目标序列右移作为输入，使用因果遮罩防止答案泄漏。每个位置预测它的下一个 token，可在一次前向中同时计算多个位置的交叉熵。

输入BOS我喜欢猫目标我喜欢猫EOS
L = − Σt log p(xt | x<t)

BOS / EOS 分别表示序列开始 / 结束。训练反向传播更新参数；不同 Transformer 可采用不同训练目标，例如掩码预测。

INFERENCE

预测 → 选择 → 追加 → 再预测

先处理提示词，再把新 token 逐步加入上下文。KV cache 复用已有位置的 K、V，避免每步重复计算全部前缀，但通常仍有逐 token 依赖。

固定序列教学演示，不调用语言模型。真实输出来自词表概率分布的选择或采样；普通推理不更新模型参数。

全局连接，也有成本

标准全注意力的两两交互为 O(n²d)，普通实现显式保存 O(n²) 权重。整层还包括投影与 FFN，不能只计算注意力矩阵的成本。

n → 2n序列长度翻倍n² → 4n²注意力配对数约 4 倍

这不意味着整模型耗时或显存必然恰好 4 倍。FlashAttention 等方法可减少中间矩阵存储与内存读写；稀疏、局部等变体则改变交互模式。

06 /

把容易混淆的边界说清楚

没有 RNN 的递推，它怎么知道 token 的顺序？

单独的双向自注意力对输入排列具有等变性，不能自行区分绝对顺序。模型需注入位置结构：原始模型把正弦 / 余弦位置编码加到嵌入上，也可学习位置嵌入；后续模型还使用相对位置或 RoPE 等机制。因果遮罩本身也约束了可见方向，但不能把它等同于完整的位置编码。

Self-Attention 与 Cross-Attention 有什么区别？

Self-Attention 的 Q、K、V 来自同一序列的表示；Cross-Attention 的 Q 来自当前处理序列，K、V 来自另一个序列。例如翻译时，解码器用自身表示作 Query，读取编码器输出。常见纯文本 Decoder-only 模型没有独立的编码器交叉注意力层。

残差与 LayerNorm 各自解决什么问题？

残差把子层输入加回输出，为信息与梯度提供直接通路；LayerNorm 通常在每个 token 的特征维上做归一化，帮助稳定优化。它不是跨 batch 统计的 BatchNorm。Pre-LN 与 Post-LN 的差别是归一化放在子层之前还是残差相加之后。

Transformer、语言模型和 ChatGPT 是同一个概念吗？

Transformer 是架构；语言模型是建模语言概率的模型类别；ChatGPT 是面向用户的产品。架构不直接规定任务或产品。Transformer 也可用于图像，语言模型也可以由 RNN 等其他架构实现。

是不是模型越大、注意力头越多就越好？

效果取决于数据、目标、优化方法、结构和算力预算的配合。头数增加也可能缩小每头维度，不能直接推导出更强能力。长上下文也不等于能可靠利用每一处信息；学习能力、访问能力和实际任务效果需要分别评估。
