## 最终未通过项

- **mpx：原 26 条断言全部通过。** 此前 c3 因旧安装运行时仅传一个参数而扣分；当前校准使用仓库的 Web 生命周期，实际派发 `[query, query]`，该扣分已撤销。
- **mpx2web / case 2 / c3：视频 URL 重复解码。** 对 Vue Router 已解码的 query 再执行 `decodeURIComponent`，破坏 URL 中的转义路径或签名。
- **mpx2web / case 2 / c6：地区选择器绑定失效。** 在原评测安装编译器下，`value@web`、`range@web` 中的 Mustache 成为字面字符串，实际组件无法正确使用地区选项。

## 原断言未覆盖的问题

- **mpx：** 错误文章首屏在客户端接管时重新加载、清空错误状态，并抛出 `HierarchyRequestError`。
- **mpx2web：** 从错误文章页切换到有效文章 id 后，没有重新加载，页面仍停留在错误状态。

上述问题由先前的独立 SSR/client bundle 与 JSDOM 检查复现，单列为扩展验收缺陷，未改变原 26 分分母。因此 SSR 用例的 5/5 不等于完整 SSR 需求全部通过。
