# 选项应用需求

本题验证构建配置、路由注册和跨页面通信，需要最小应用结构。首页同时承载样式示例；选择页用于 ready 通知和确认回传；packageA/index.mpx 只用于验证分包路由，已由执行器复制，不必修改。

- 红、蓝卡片的同名类不能相互覆盖；240px 横排中的两个 layout-cell 各占 120px。
- 两个 theme-card 保留调用方 warm-tone、cool-tone 颜色和 spaced-label 的 12px 内边距，以及默认外部类约定。
- Web 的 200rpx 示例块在 375px 和 750px 视口都显示为 100 CSS px，28rpx 字号显示为 14 CSS px；微信尺寸不变。
- 点击首页选择按钮先显示“正在选择”，确认后回传所选文案；navigator 直接进入选择页仍可使用。
- 微信保留胶囊布局；Web 不执行微信胶囊 API，且自定义导航不与系统导航重复显示。
- Web 使用 history 路由，页面和静态资源的部署前缀为 /help-demo/；保留主包、分包页面注册和微信独立分包配置。
