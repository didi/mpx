# TaskBoard 页面需求

创建一个任务看板页面。页面内置一组任务数据，每项包含 `taskKey`、`title`、`category` 和 `completed`，并提供“全部 / 工作 / 生活”三个筛选项。

页面需满足以下功能：

- 顶部展示页面标题和当前筛选结果数量。
- 点击筛选项后切换当前分类，并明显区分选中状态；当前筛选项使用半透明主题色背景突出显示。
- 点击任务卡片后切换其完成状态，并在视觉上区分已完成与未完成任务。
- “全部 / 工作 / 生活”三个筛选项和每个任务卡片都是点击目标，均需实现点击态反馈。
- 筛选结果为空时展示空状态文案。
- 页面支持通过 `category` 参数指定初始分类；参数值不在可选分类中时回退到“全部”。
- 主体内容超出可视区域时可以纵向滚动。
- 系统导航栏标题显示为“任务看板”。

实现方式：

- 使用组合式 API。
- 使用原子 CSS。
- 不使用 style 或 wx:style 定义样式
