# Iteration 10 评测结果（eval-6/7/8 重跑）

## 重跑设置

- 仅重跑 eval-6、eval-7、eval-8，输入、提示和断言沿用 iteration-10 现有配置。
- 每个 eval 分别执行 `mpx2rn`、`mpx2rn-simple`、`no_skill` 三组，共 9 个隔离样本。
- 生成阶段按既有评测约定不运行编译校验或 ESLint。
- 评分器的 17 项回归测试全部通过；随后使用同一 checker 重算 6～8 的 grading。
- eval-0～5 未重跑，其历史结果保留在整体统计中。

## 主要观察

- 两版 Skill 在 eval-6/7 均满分，稳定覆盖组件 API 组织、状态同步、内联事件参数、`wx:class` 与跨端样式约束。
- eval-8 精简版满分；评分器将仅含注释或空白的 `<style>` 视为空区块。筛选项和任务卡片必须使用 `hover-class` 提供点击态，`hover:` / `active:` / `focus:` / `visited:` 均按 RN 不支持处理，因此完整版仅失败 a12。
- no_skill 在三个新建任务中均明显落后，尤其 eval-7/8 暴露了组合式 API、显式暴露、动态类和页面 JSON 约束的缺失。

## 解释限制

每个配置每个 eval 只有 1 次运行，无法估计随机性。自动评分仍主要是静态文本与有限语义分析；本轮按设计未做真实编译、ESLint 或运行时验证，也没有可用的 token、工具调用和精确耗时数据。
