# Iteration 9 评测结果

## 评测设置

- 对比配置：`mpx2rn`、`mpx2rn-simple`、`no_skill`
- 用例：沿用 iteration-8 的 9 个 eval，覆盖存量适配与从零创建
- 每个配置每个用例执行 1 次，共 27 次独立执行
- 评分：使用 iteration-9 的 `grade.py`，三组应用相同的 110 条断言；eval-4 按新输入重新执行
- 执行模型：继承当前 Codex 会话；运行通知未提供 usage，因此不记录 Token、工具调用与耗时指标
- 为保证一次性生成质量可比，执行阶段不运行编译校验或 ESLint，也不允许读取评测断言与其他组输出

## 总体结果

| 配置 | 通过断言 | 加权通过率 | 每用例通过率均值 |
| --- | ---: | ---: | ---: |
| `mpx2rn` | 106 / 110 | 96.36% | 96.03% |
| `mpx2rn-simple` | 100 / 110 | 90.91% | 90.25% |
| `no_skill` | 76 / 110 | 69.09% | 64.00% |

`mpx2rn` 相比 `no_skill` 的加权通过率提升 27.27 个百分点；`mpx2rn-simple` 提升 21.82 个百分点。完整版领先精简版 5.45 个百分点。

## 主要观察

- 两版 Skill 在 eval-1、eval-2 上均满分，而基线分别只有 2/9、3/9；Skill 对 Mpx 模板指令、事件传参、API proxy、不支持生命周期/API 和 RN 页面滚动差异的增益最明显。
- 完整版在数值字重、动态背景开关、边框样式、`background-repeat`、文字装饰条件处理、hover 交互及新的 `l10`、`l11` 共 8 条断言上胜过精简版。
- eval-4 的三类 margin 场景已拆开：完整版同时通过相邻兄弟折叠 `l10`、父子同向折叠 `l11` 和 Flex 子项不折叠反例 `l12`；精简版与基线仅通过 `l12`，表明反例没有诱导模型误清除正常间距。
- 精简版仍在 eval-5 额外通过动态 CSS 变量 `enable-var`，精简工作流没有在所有细节上弱于完整版。
- eval-8 三组全部满分，区分度不足；后续迭代应提高原子类页面用例难度或增加更具 Mpx2RN 特异性的断言。
- 110 条断言中有 75 条三组全部通过，2 条三组全部失败。全部失败的是伪元素真实节点替代和单字体 `font-family`；新的 `l10`、`l11` 已能区分完整版 Skill 与其他两组。

## 解释限制

本轮每个配置仅执行 1 次，不能估计模型随机性；自动评分以正则和文本匹配为主，适合横向筛查，但不能替代编译与运行验证。结论应视为一次性生成质量对比，而不是生产可用性的最终证明。
