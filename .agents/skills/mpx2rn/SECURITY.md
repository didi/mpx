# 安全声明

本声明覆盖本 Skill 随附的脚本。编译校验会执行宿主工程的构建代码，宿主配置与依赖的行为不受本 Skill 隔离或限制。

## 一、脚本清单

### scripts/compile-validate.js

- **用途**：对指定 `.mpx` 页面或组件进行真实编译校验，汇总错误与警告；默认目标为 `ios`，支持显式指定其他目标。
- **行为**：读取输入文件及上级目录的 `package.json`，自动探测或使用指定的宿主工程根目录；从宿主工程解析并加载 Mpx CLI、Webpack 等本地依赖，加载工程配置，按目标平台执行构建。将编译产物与 source map 写入系统临时目录 `mpx-compile-validate/<hash>`，默认在构建返回后递归删除本次产物目录；异常中断或通过模块 API 设置 `cleanup: false` 时可能保留产物。向终端输出诊断信息，支持 JSON 输出。
- **语言**：Node.js（JavaScript）。
- **平台**：跨平台，需宿主工程具备兼容的 Node.js 与 Mpx 构建依赖。

### scripts/strip-using-components-loader.js

- **用途**：为旧版宿主编译插件提供跳过子组件编译的兼容处理。
- **行为**：由编译校验脚本按宿主版本启用，在内存中将输入源码里的 `usingComponents` 对象替换为空对象，再通过 Webpack loader 回调返回；不直接改写源文件，也不执行输入源码。正则匹配使用的 `RegExp.exec()` 不属于代码执行。
- **语言**：Node.js（JavaScript）。
- **平台**：跨平台，运行于宿主 Webpack 构建环境。

### scripts/strip-using-components-loader.test.js

- **用途**：验证兼容 loader 对 `usingComponents` 的转换行为。
- **行为**：由 Jest 加载本地 loader，对内置源码字符串进行断言；测试代码本身不联网、不读写业务文件、不启动子进程。测试运行器的配置、依赖加载及缓存行为由所用 Jest 环境决定。
- **语言**：Node.js（JavaScript / Jest）。
- **平台**：跨平台，需可用的 Jest 测试环境。

## 二、网络行为

- 随附脚本没有直接网络请求、下载、上传或遥测逻辑，没有固定访问的 API 域名。
- 不调用 `curl` / `wget`，不执行 `npm install` / `pip install`，不自动下载依赖或远程代码；依赖须由宿主工程预先提供。
- 构建时加载的宿主配置、插件和 loader 可能自行联网、下载资源或外发数据，目标地址由宿主实现决定。本 Skill 不提供网络隔离，不能据此保证整个构建过程离线。
- 诊断输出可能包含本地路径、源码片段及宿主构建错误原文；脚本本身不外发这些内容，分享日志前应检查其中的敏感信息。

## 三、执行行为

- 脚本不使用 `curl | bash` / `curl | sh` 等管道执行，不调用 `child_process` 或通过 shell 启动子进程，也不直接使用 `eval()` / `new Function()` 执行字符串代码。
- 文件路径、`--project-root`、目标平台等参数来自调用者，通过路径与构建 API 使用，不拼接为 shell 命令。
- `require.resolve()` / `require()` 会从宿主工程解析并执行本地依赖；CLI 初始化与 Webpack 构建会执行工程配置、插件、loader 及编译期代码。这是真实构建，不是纯文本静态检查，仅应在可信的工程与依赖上运行。
- 编译期间会切换当前进程工作目录，设置目标平台相关环境变量及 `NODE_ENV` / `BABEL_ENV` 为 `production`。结束时恢复工作目录；脚本未恢复环境变量，通过模块 API 调用时会影响同一进程的后续操作。

## 四、权限

- 使用普通用户权限运行，不需要 root、管理员权限或 `sudo`；不执行 `chmod` / `chown` / `setuid` 等权限变更。
- 需要读取目标源码、宿主配置、依赖及探测路径，并在系统临时目录创建、写入和删除本次构建产物。脚本不直接修改业务源文件，兼容 loader 仅处理内存中的源码。
- 脚本不修改系统配置、定时任务或 shell 启动文件。宿主构建代码继承当前进程权限，仍可能读写其他路径或启动外部进程；临时输出目录与关闭 Webpack 缓存的设置不构成沙箱。
- 临时产物可能含源码及 source map；清理失败或构建异常时可能残留，手动清理应仅针对本次生成的目录。

确认：以上声明与本 Skill 随附脚本的行为一致；后续修改脚本或新增执行、联网、文件访问及权限行为时，应同步更新本声明。
