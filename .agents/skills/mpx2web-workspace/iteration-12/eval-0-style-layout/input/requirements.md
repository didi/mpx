# 输出要求

- 输出适配后的完整工程文件；同一套交付文件同时用于微信小程序和 Web。
- 保持样式页面原有外观：红、蓝卡片的同名样式互不影响；“甲”和“较长的乙”在 240px 行内各占 120px；两处标签继续显示调用方指定的颜色和 12px 内边距。
- 保持微信小程序原有首页、选择页、页面通信、分包、资源和导航交互可用。
- Web 的运行时路由使用 history，页面基础路径与静态资源 publicPath 均为 `/help-demo/`；首页、选择页、样式页及两个分包页面继续注册。
- Web 不调用微信胶囊 API，且不会同时显示系统导航与页面自定义导航；微信原导航行为保持不变。
- 在 375px 和 750px 的 Web 视口下，输入中的 200rpx 示例块均显示为 100 CSS px，28rpx 字号均显示为 14 CSS px；微信尺寸结果保持不变。
- 交付说明写清 workers 和独立分包在 Web 输出中的实际边界。
