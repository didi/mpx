# 页面约定

- 主入口：src/pages/style/index.mpx。
- 现有页面与子组件的外观、布局和交互以输入源码为基准，在两端保持一致。
- “甲”和“较长的乙”两格平分 240px 宽的行，各占 120px，不能随文字长短改变宽度。
- 暖色标签为 #bb3311，冷色标签为 #2255cc，两处标签内容区域均有 12px 内边距；颜色与间距继续由调用方传入的样式类决定，不写死在子组件中。

## 从零生成帮助面板

### 交付范围
创建 src/components/help-card.mpx 面板和 src/components/help-item.mpx 子组件。面板实际引用帮助项，由帮助项承载说明、展开/收起入口和“查看完整帮助”入口；不要只创建空文件或把全部内容仍写在面板中。已有页面与组件另按原要求适配。

### 数据与交互
- 面板接收 title、description、helpUrl 三个字符串属性，显示标题并把所需数据传给帮助项。
- 说明初始收起；点击“展开说明”显示说明，再点击“收起说明”隐藏。展开状态由面板或子组件管理均可。
- 点击“查看完整帮助”，使用该实例传入的 helpUrl 进入项目已有 WebView 页面。
- 同一套 .mpx 源码用于微信小程序和 Web，不生成两套业务实现；选项式或组合式 API 均可。

### 样式与调用约定
- 面板和帮助项的样式不影响页面其他区域。只读宿主页已有 .title 和 .action 区域，原有字号、颜色和间距须保持。
- 调用方通过面板上的 item-class 外部类控制帮助项内部内容区域的文字颜色和内边距，而不是只修改面板外壳。
- 宿主页的两处调用分别传入 help-red（#c62828、12px 内边距）和 help-blue（#1565c0、20px 内边距）；这些样式继续由调用方定义，不按标题或实例位置写死在子组件中。
- “查看完整帮助”按钮背景由 --btn_wrapper_bg 控制，未定义时为 #2A2F3F；宿主定义或修改变量后使用新颜色。外部类控制文字与间距，CSS 变量控制按钮背景，两者互不替代。

### 已有项目环境
- 源码模式 wx，项目已安装 Mpx API Proxy，两端构建入口已存在。需要的配置可合入本题已有 mpx.config.js，并保留原有页面适配。
- 已注册 /pages/common/webview，接收 url 查询参数；容器按对应平台路由约定取得原地址作为 web-view 的 src。
- helpUrl 是未经过路由参数编码的完整 HTTPS 地址，可能包含自己的查询参数和百分号转义；容器取得的地址须与原值一致。
- fixtures/src/pages/common/webview.mpx 是已有容器，fixtures/src/pages/review/index.mpx 是调用宿主；均只读，不是生成组件的答案，不要求重新实现容器或 H5 通信桥。
- 当前仅做静态源码评审，不运行宿主页或外部链接。实际链接的微信业务域名与 iframe 许可属于环境条件，未提供有效链接不计为源码失败。
