# 项目约定

- 主入口：src/pages/content/index.mpx。原有外观与功能以输入源码为准。
- Web 环境没有提供位置、扫码、分享的业务服务协议。不得伪造这些能力的结果；无法形成真实链路时，应如实保留未接入边界，并保证其他功能可用。
- src/vendor/native-scanner 是只读依赖，不可修改，交付时随依赖一起保留。
- foo 是既有微信插件，component 展示服务卡片；provider 的 wx123 是脱敏占位，不要求下载或申请插件。Web 没有对应实现，不得下载、冒充服务或伪造插件内容；Web 产物不能依赖不可用的插件实现，未接入状态需如实交付。
- 保留微信所需的配置。交付时说明现有声明在目标端的适用范围及未完成事项，不要求补充未经提供的业务协议。
- videoUrl 路由参数提供按 URL 查询参数编码一次的有效 HTTPS 视频地址。Web 保留核心播放功能；辅助信息在目标端无法可靠提供时，允许降级并说明原因。微信原功能保持不变。
- 有效视频地址及微信位置、相机权限由测试环境提供；缺失时标为环境未就绪。
