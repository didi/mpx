# 输出要求

- 输入为现有微信小程序 `.mpx` 页面，只输出 `src/pages/store-picker/index.mpx` 和 `src/pages/catalog/index.mpx`；不新增组件文件、平台副本、第三方依赖或位置、地图、媒体、网络等环境 API。
- 两个输出页面同时用于微信小程序和 Web。先按目标版本源码判断组件及所用属性、事件是否真实支持；已支持的公共能力保持共用，不能因为部分能力缺失而重写整个组件。
- 项目没有提供现成 Web 组件、SDK 或适配层时，不在页面内临时补造按钮选择器、静态列表、轮播、图片加载器或弹层。保留并真实隔离微信实现，在相邻 Web 边界留下具体 `TODO(web)`，说明缺少的能力以及业务需要按实际组件、数据源、SDK 和交互方案实现的接入点。
- TODO 可以配合 Web 边界展示当前状态或未接入说明，但不能把 TODO 本身渲染成页面文字，也不能声称对应 Web 能力已经完成；只有输入中已经存在可用 Web 方案时才接入并复用原业务状态。模板、script、style 中的注释分别使用 `<!-- TODO(web): 具体业务接入说明 -->`、`// TODO(web): 具体业务接入说明`、`/* TODO(web): 具体业务接入说明 */`。
- 保留输入中的业务数据、稳定 id、地区与门店状态、活动状态、商品选择状态和筛选草稿/确认逻辑，不硬编码或伪造结果。
