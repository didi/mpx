# 输出要求

- 输入是现有 Mpx 微信小程序文章页；目标是在输出 Web 时同时支持服务端首屏渲染和浏览器客户端接管，不是另建一套通用 Vue SSR 应用。
- 输出适配后的文章应用、页面、服务和状态文件；同一套交付保持微信小程序文章页原有行为。
- Web SSR 路由使用 history，基础路径为 `/help-demo/`。访问文章 a 或 b 时，服务端从当前路由 query 取得 id，等待文章数据后再渲染首屏。
- 将原文章状态域整体迁移到 `@mpxjs/pinia`，微信与 Web 共用同一个 Pinia store、状态字段和加载 action，不保留第二套旧 Store；每次 SSR 请求创建独立实例，服务端状态能够通过 Mpx 默认流程或正确的自定义流程恢复到客户端。
- 服务端可达代码不能访问 `window`、`document`、`navigator` 等仅浏览器存在的对象。
- 微信文章页继续通过原 `onLoad(query)` 调用共享 Pinia action 加载文章，保留加载、错误、正文和展开交互。
