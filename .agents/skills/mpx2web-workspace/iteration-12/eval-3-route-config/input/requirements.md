# 项目约定

- 入口为 src/pages/home/index.mpx，关联页为 src/pages/choice/index.mpx。原有外观与功能以输入源码为准。
- Web 部署到 /help-demo/，页面支持直接访问与刷新；交付所需的服务器配套说明。
- Web 在 375px、750px 两种视口下，200rpx 示例块均为 100 CSS px、28rpx 字号均为 14 CSS px。微信尺寸规则保持原样。
- Web 如有自行确定的设计尺寸，交付时说明依据及待确认事项。
- packageA 是微信独立入口，packageB 是普通分包；两页内容和入口均须保留。Web 允许共用应用，不要求新建独立站点。
- workers 目录是已声明的备用计算资源，本题没有启动任务或消息通信需求，不新增调用。
- 保留微信所需的声明。交付时说明这些配置在目标端的适用范围；非必需的加载优化未实现时如实说明，不要求为此重写构建系统。

## 文章详情页 SSR 交付目标

- 详情页为 /pages/article/index，id 查询参数指定文章。每次访问首次返回的 HTML 应包含对应标题和正文。
- 客户端接管已有页面和数据，不重复加载同一篇文章；原有交互、默认文章及错误提示保持正常。
- 沿用 src/services/article.js 的数据和异步接口，不改变返回结果或等待语义。
- 输入是使用 createStore 的既有小程序页面，文章、加载状态和错误信息由 src/store/article.js 管理。适配后仍须保留这些状态及原有功能；不要求维持原文件内部结构。
- SSR 输出沿用 Mpx 官方支持的状态管理与注水方案，不另建状态同步协议；微信原有加载流程保持正常。
- 已有构建与宿主环境见 fixtures/runtime-contract.md。
