# 输出要求

- 输出适配后的完整工程文件，保持微信小程序原有页面、配置、分包、资源和交互可用。
- Web 部署路径为 `/help-demo/`，主包页面及两个分包页面均可访问；页面地址直接打开或刷新时仍能进入对应页面。
- 在 375px 和 750px 的 Web 视口下，输入中的 200rpx 示例块均显示为 100 CSS px，28rpx 字号均显示为 14 CSS px；微信尺寸结果保持不变。
- `/pages/article/index?id=a` 与 `/pages/article/index?id=b` 的首次 SSR HTML 分别包含对应文章的标题和正文。客户端接管后继续使用同一文章状态，不重复加载已经取得的数据。
- 不同 SSR 请求之间不能共享文章状态；连续加载不同文章时只保留最新请求对应的文章、加载状态和错误状态；服务端执行过程不能访问仅浏览器存在的对象。微信文章页原有加载、提示、正文和交互保持正常。
- 交付说明写清 Web 导航尺寸依据、`/help-demo/` 刷新所需的服务器条件，以及 workers、独立分包和 preloadRule 在 Web 输出中的实际边界。
