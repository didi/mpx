# v2.11.3

## ✨ New Features

- **响应式调试**（[使用文档](https://mpxjs.cn/guide/composition-api/reactivity-debugging.html)）
  - 新增开发态渲染调试钩子 `onRenderTracked` / `onRenderTriggered` 与选项式 `renderTracked` / `renderTriggered`，支持小程序、RN 与 Web，便于定位渲染依赖及触发更新的来源。
  - 组合式 `computed` 与 `watch` 系列支持 `onTrack` / `onTrigger`，选项式 `watch` 和实例 `$watch` 同样支持调试选项；回调提供依赖对象、操作类型及相关值信息，仅在开发环境生效。

- **跨端输出 React Native**
  - `enable-var` 新增 `"use"` 模式，仅预留动态使用 CSS 变量的能力，减少额外开销；首次无变量声明、后续需要新增声明时，需从首次渲染起设置 `enable-var="{{true}}"`，相关能力在首次渲染时确定。
  - 优化动画、`swiper` 与 `movable-view` 的 worklet 闭包捕获，减少不必要的跨线程数据传递。

## 🐛 Bug Fixes

- **跨端输出 React Native**
  - 修复 CSS 变量声明动态增删导致子组件重新挂载、旧变量残留的问题，删除本地声明后可正确回退到父级变量。
  - 修复已启用的 CSS 变量使用、文本透传与动画能力在后续移除时产生不必要报错的问题。
  - 修复 `label` 内点击 `radio` / `checkbox` 导致重复触发变更的问题，并修正 `radio-group` / `checkbox-group` 的 `change` 事件类型。
  - 补齐 `form` 的 `reset`、`picker` 的 `cancel`、`camera` 的 `stop` 事件对象，修复相机事件缺失目标节点属性，以及 `video` 部分事件类型错误的问题。
  - 修复日期选择器切换年月时闰年天数计算错误的问题。
  - 修复 `sticky-header` 的 `offset-top` 未正确参与吸顶位置与事件判断、首次测量前异常位移，以及吸顶节点注册标识不一致的问题。
  - 修复跨页面调用 `hideLoading` / `hideToast` 后提示层未清理、返回原页面仍残留的问题。
  - 修复 Canvas 平台专用渲染分支被覆盖，以及图片加载回调替换时监听清理错误的问题。
  - 修复 `swiper` 跨线程回调引用未随组件更新而刷新的问题。

- **跨端输出 Web**
  - 修复 tabBar 页面容器尺寸与当前页面标识同步问题，覆盖异步页面首次挂载及缓存页面恢复场景。
  - 修复下拉刷新获取页面节点错误，以及事件未携带参数时访问目标节点导致报错的问题。
  - 修复 `sticky-header` 设置 `offset-top` 后吸顶位置与 `stickontopchange` 事件判断不一致的问题。

- **核心与类型**
  - 修复生命周期钩子嵌套执行后实例上下文未正确恢复的问题；隔离自定义 `errorHandler` / `warnHandler` 抛出的异常，避免中断后续处理。
  - 修复 TypeScript 5 下 `@mpxjs/store` 的 `mapMutations` / `mapActions` 数组映射类型推导问题。
